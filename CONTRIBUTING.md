# Contributing

Open a pull request with the repository URL, a concise capability description, license,
installation instructions, and a reproducible example or meaningful test.
Disclose runtime dependencies, external accounts and implementation limitations.

Keep entries in the appropriate category and update catalog.json consistently.
Avoid duplicates, unverified performance claims, and claims of registry acceptance without a listing URL.
For MCP servers, test initialization, tool discovery with schemas, and at least one tool call.
Repository inclusion does not imply production or security certification.
